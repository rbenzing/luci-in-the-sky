# Security Policy

## Supported Versions

The project is currently in beta. Security fixes are expected to land on the latest release line.

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |
| < 1.0.0 | No |

## Reporting a Vulnerability

Please do not open a public issue for vulnerabilities in this tool or for exploit details that could put users at risk.

Instead:

1. Use GitHub's private vulnerability reporting flow for the repository, if enabled.
2. If that is not available, contact the maintainers through a private channel published by the repository owner.
3. Include affected version, impact, reproduction details, and any proof-of-concept material needed for validation.

We will aim to acknowledge receipt promptly, validate the report, and coordinate a fix and disclosure timeline responsibly.

## Scope

This policy applies to vulnerabilities in the LuCI-RedTeam codebase itself.

It does not grant permission to test third-party systems without authorization. If you discover a vulnerability in a deployed LuCI/OpenWrt target, coordinate disclosure with the relevant vendor, maintainer, or owner.
